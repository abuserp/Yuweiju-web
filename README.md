# 余味居

> 做饭不一定要有灶台，一口锅，一把火，也能烧出一手好菜。
> 但有了灶台，就会有常客，就会有挂念。

一家开在炎国街角的小馆子。老姜跑堂，余掌勺，白天招呼客人、点单、传菜，夜里结账、进货、排明天的菜牌。

明日方舟非商业同人作品。纯静态网页，无需安装依赖或构建。

## 开始游戏

电脑上直接打开 `index.html` 即可游玩；也可以将本目录部署到静态网站，在电脑或手机浏览器中访问。

- 电脑：WASD／方向键移动，空格交互，Q 倒掉手上的菜，数字键选择面板选项。
- 手机：在游戏画面内按住拖动，点击下方按钮交互或倒菜，面板选项直接点击。
- 存档保存在当前浏览器中，可从标题页继续游戏或清空存档。
- 首次开始或继续游戏时，会显示场景、角色与菜品贴图的加载进度，准备好后再进入游戏。同一页面内复用已加载的图片；当天客人确定后，会在营业期间后台预载对应剧情，播放前只等待未完成的图片。网络失败时可重试。
- 内置剧情立绘采用保留透明背景和原分辨率的 WebP，以减少下载量；剧情回想和立绘浏览使用同一套图片。

## 玩法

- 白天接待客人，根据口味点单，到传菜口取菜并送到桌前。连续上对口味的菜可以提升连击。
- 缺料时可以叫鼎丰楼外卖救场；打烊后结算收入、房租和食材损耗。
- 夜间采购食材、管理保鲜批次、调整菜牌，随着默契和烹饪熟练度解锁新菜。
- 内置三组特殊来客：望、杜遥夜与老鲤、孑与槐琥，共八段到访剧情。完成接待后推进故事，获得菜谱与默契奖励。
- 标题页的「剧情回想」可以自由观看故事和浏览立绘，不影响存档进度。

## 客人数据包

标题页支持导入 JSON 客人包。格式参考 `mods/example-pack.json`，使用说明见 `mods/README.txt`。

示例包和 `mods/optional-guests.json` 均为手动导入，不默认加入游戏。通过网站运行时，也可以把需要加载的文件名加入 `mods/index.json`。

## 发布

将本目录内容放入新仓库后，将静态站点入口设置为根目录的 `index.html`。发布时保留 `art/`、`avg/`、`audio/`、`css/`、`js/`、`mods/` 的相对路径及文件名大小写。
